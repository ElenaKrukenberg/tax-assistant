# Measured before writing this file: `pip install ragas` into the app venv pulls 51
# packages and upgrades pydantic 2.5.0 → 2.13.4 along with langchain and datasets.
# fastapi 0.103.2 is not built for that pydantic, so the app would be the price of the
# evaluation. Nothing here is imported by the application — ragas_score.py reads the
# recorded answers from results/ and never touches backend code.
#
# Every pin below is load-bearing, and the reason is not the usual one. ragas imports
# `langchain_community.chat_models.vertexai` at package import time, and that module was
# deleted when langchain-community was sunset: with community 0.4.2 every ragas release
# from 0.2 to 0.4.3 fails on `import ragas` before any of its own code runs. Community
# 0.3.27 is the last line that still ships the module, which in turn holds langchain-core
# on 0.3.x and langchain-openai on 0.3.x. Bumping any one of the four alone reproduces
# the ModuleNotFoundError.
